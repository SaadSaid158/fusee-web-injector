# Fusee Web Injector  

A web-based payload injector for Fusée Gelée (Nintendo Switch exploit) that runs directly in the browser.  

## Features  
- Injects payload directly in the borwser, so no need for external tooling
- Simple clean interface, straight to the point
- Load and inject custom payloads that you can upload  

## How to Use   
1. **Connect your Nintendo Switch in RCM mode via USB**  
2. **Open [Fusee Web Injector](https://saadsaid158.github.io/fusee-web-injector/)** 
3. **Upload or select a payload**
4. **Click "Connect Switch" and choose "APX" from the list.**
5. **Click "Inject" and wait for completion**  

## Supported Browsers   
- Chrome (Recommended)  
- Firefox  
- Edge
- Any other browsers that have support for WebUSB

### Run Locally  
Just open `index.html` in a browser.
